# Домашняя работа: Docker

Я запустил приложение со счётчиком через Docker Compose.

## Как запустить

сначала скопировать настройки:

```sh
cp .env.example .env
```

Потом собрать и запустить приложение:

```sh
docker compose up --build -d
```

Открыть приложение можно по адресу <http://localhost:8080>

В файле `.env` можно поменять порт и приветствие:

- `APP_PORT` — порт на компьютере, по умолчанию `8080`.
- `GREETING` — текст приветствия.

## Как я проверил

Посмотрел начальное значение счётчика и два раза увеличил его:

```sh
curl -fsS http://localhost:8080/
curl -fsS -X POST http://localhost:8080/increment
curl -fsS -X POST http://localhost:8080/increment
curl -fsS http://localhost:8080/
```

Сначала счётчик был `0`, после двух запросов стал `2`.

потом остановил приложение и запустил снова:

```sh
docker compose down
docker compose up -d
curl -fsS http://localhost:8080/
```

После запуска счётчик всё ещё был `2`. Первый запрос сразу после запуска не
сработал, потому что приложение ещё загружалось. Я подождал и повторил его —
тогда получил ответ со счётчиком `2`.

Данные хранятся отдельно от контейнера, поэтому обычная команда
`docker compose down` их не удаляет. Для этой проверки нельзя добавлять `-v`:
с ним Docker удалит и сохранённые данные.
